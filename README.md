# Web Cambio Social

Guía práctica informativa, perenne y multiidioma (ES, CA, EU, GL) dirigida a personas en España desencantadas con la política electoral, centrada en **Ámbitos**, **Acciones** cotidianas constructivas y **Recursos** reales para impulsar el cambio social fuera de las elecciones.

## Estado actual

Este proyecto está en fase de planificación mediante **Wayfinder** en las issues de GitHub.

- Consulta el vocabulario del dominio en [GLOSSARY.md](./GLOSSARY.md).
- Consulta el mapa de decisiones en las issues etiquetadas con `wayfinder:map`.
